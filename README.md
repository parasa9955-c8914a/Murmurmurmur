# Murmur_2026

A starter Python project for deploying a Hugging Face heart sound classification model with Streamlit.

## Project overview

This repository contains the project structure and setup files needed to build a Streamlit app that loads and serves a heart sound classification model. The implementation of the actual model is intentionally left for later.

## Files and folders

- `.venv/` - Python virtual environment for local development.
- `src/` - Placeholder folder for reusable Python modules and library code.
- `.env` - Environment configuration file for local secrets or deployment settings.
- `.gitignore` - Ignore rules for Python, Streamlit, Hugging Face, and VS Code artifacts.
- `app.py` - Streamlit application entrypoint.
- `requirements.txt` - List of Python dependencies.
- `.vscode/settings.json` - VS Code workspace settings configured to use the `.venv` interpreter.

## Setup

1. Create and activate the virtual environment:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the app:

   ```bash
   streamlit run app.py
   ```

## Notes

The app currently contains a deployment-ready template and does not yet implement the heart sound classification model itself.
